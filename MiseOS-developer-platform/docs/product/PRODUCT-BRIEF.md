# Product Brief

## Product

MiseOS Developer Platform is a character-native control plane for discovering, validating, executing, and governing reusable AI-agent capabilities.

## Problem

Developer teams are shifting from writing every change manually to supervising code, workflows, and decisions produced by AI systems. Existing tools are fragmented across model providers, scripts, CI services, prompt libraries, and repository bots. They commonly lack consistent permission boundaries, evidence requirements, portable manifests, and a shared operational view.

## Solution

MiseOS packages developer capabilities as registry manifests with bounded runtime handlers. The platform exposes those capabilities through a CLI and REST API, then extends them through GridOps dashboards, GitHub Apps, proof gates, and marketplace distribution.

## Initial users

- AI application developers who need model-agnostic orchestration.
- Platform and DevOps teams governing repository automation.
- Open-source maintainers supervising AI-generated pull requests.
- Technical founders packaging repeatable workflows.
- Enterprise security and compliance teams requiring auditability.
- Character and media creators turning IP into useful digital services.

## Primary use cases

1. Validate a canonical catalog of agent capabilities.
2. Execute safe, workspace-scoped repository operations.
3. Inspect permissions, status, version, and handler metadata.
4. Run policy, release, workflow, SBOM, and repository-health checks.
5. Expose capabilities through GitHub-native review and maintenance agents.
6. Publish governed agents and workflows into a marketplace.
7. Meter execution and offer team or enterprise subscriptions.

## Non-goals for the current release

- Unrestricted shell execution.
- Autonomous production deployment mutation.
- Credential rotation or custody.
- Claims of AGI, consciousness, or self-awareness.
- Token, NFT, or reward issuance inside the core runtime.

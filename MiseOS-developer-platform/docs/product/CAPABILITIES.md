# Developer Tool Capabilities

## Current platform capabilities

The current repository implements a canonical registry, bounded TypeScript runtime, Fastify API, and CLI around 23 manifests.

| Capability family | Functionality |
|---|---|
| Registry | Catalog loading, manifest lookup, schema validation, count invariants, status handling |
| Runtime | Explicit handler mapping, workspace-scoped file generation, structured results, disabled-item enforcement |
| API | Health, catalog, manifest lookup, capability execution, OpenAPI endpoint, rate limiting, security headers |
| CLI | Catalog listing, validation, diagnostics, JSON execution input, workspace selection |
| Repository health | Reliability scoring, configuration guidance, stewardship workflows |
| Policy and trust | Policy checks, policy engine, attestations, trust graph, proof-oriented gates |
| Delivery | Release sentinel, workflow linting, reusable workflow packs, container publishing |
| Supply chain | SBOM indexing, package adapters, schema and SDK manifests |
| Observability | Analytics engine and structured capability results |
| Experience | Documentation templates, themes, repository character surfaces |

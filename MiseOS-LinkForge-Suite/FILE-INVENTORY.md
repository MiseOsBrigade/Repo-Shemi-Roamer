# File Inventory

The suite contains eight independent repository directories under `repos/`, a
shared brand package, research and security documentation, source screenshots,
a generated demonstration packet, individual repository ZIP archives, and one
complete suite ZIP.

Each repository includes its own README, license, security policy, contribution
guide, agent instructions, change log, editor configuration, ignore rules,
Dependabot configuration, branch-ruleset template, and the code/configuration
required for its responsibility.

Use `repositories.yaml` as the machine-readable repository map and
`bundles/SHA256SUMS.txt` as the release checksum register.

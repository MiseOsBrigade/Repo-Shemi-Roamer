# LinkForge Actions

Reusable GitHub automation for LinkForge repositories and source packets.

- Composite `capture` action
- Packet integrity verification
- Reusable capture and release workflows
- CodeQL, dependency review, SBOM, artifact attestation, and release provenance
- Repository security bootstrap script for private vulnerability reporting,
  secret scanning/push protection, Dependabot, and default-branch rulesets

Review every action version and pin it to a verified full commit SHA in
production. Major tags are kept here for readability and automated Dependabot
maintenance.

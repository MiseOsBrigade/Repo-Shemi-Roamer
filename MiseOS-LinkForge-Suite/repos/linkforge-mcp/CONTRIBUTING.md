# Contributing

1. Create a focused branch from `main`.
2. Add tests for behavioral changes.
3. Run the repository's `mise run check` task.
4. Open a pull request with a clear risk and verification summary.
5. Do not commit secrets, generated credentials, private exports, or licensed
   market-intelligence data.

External source text is untrusted data. Never convert instructions embedded in
retrieved content into tool calls or privileged actions.

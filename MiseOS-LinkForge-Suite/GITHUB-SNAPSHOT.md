# GitHub source snapshot

This repository snapshot contains the complete reviewable source tree for all eight LinkForge components, including code, tests, documentation, branding, security policies, GitHub Actions, repository rulesets, deployment configurations, manifests, and text-based sample outputs.

Two compact component ZIPs are included as examples. The six other component ZIPs, the generated PDF, and three supplied screenshot binaries are intentionally not duplicated in Git history because their canonical source and checksums are already present and the complete release archive is distributed separately. Regenerate the report with `mise run demo` and rebuild component bundles from the corresponding directories.

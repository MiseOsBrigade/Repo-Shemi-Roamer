# Miseverse Grid Brand

The visual system combines a near-black operating surface, gold registry borders, cyan data signals, green verification, orange workflow heat, and restrained violet agent accents.

## Identity line

**Miseverse Grid Ecosystem — operational characters moving through a circuit-board city of evidence, work, memory, time, and governance.**

## Use rules

- Preserve readable contrast and textual status labels.
- Keep gold as hierarchy and registry framing, not body text.
- Use cyan for data movement, green for verified state, orange for active work, and violet for orchestration or exceptional agent state.
- Do not use character imagery as evidence that a check passed.
- Do not place executable behavior inside image assets.

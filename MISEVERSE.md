# Miseverse Grid Ecosystem

Repo Shemi Roamer now includes an interactive character world that maps eight visual operators to real repository traversal biases and signed, allowlisted visual workflow labels.

## Operators

- Kurogami Senpai — orchestration and release direction
- Kuro Guard — policy, monitoring, and audit
- Iron Hashi — deterministic validation and checksums
- Scale Oni — profiling and performance thresholds
- Seira — release provenance and package quality
- Streama — JSONL, telemetry, and data streams
- Build-Kun — builds, containers, and deployable artifacts
- Umami Code — reusable code composition and integration

## Launch locally

```bash
npm run build:miseverse
npm run verify:miseverse
npm run preview:miseverse
```

Then open `http://127.0.0.1:4173/miseverse/`.

The interactive surface lives in [`docs/miseverse/`](docs/miseverse/). Images remain passive. The signed manifest controls hotspot identity and allowlisted labels; simulations do not execute code or write to the repository.
